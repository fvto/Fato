# HFPA defect colors

`HFPA_Defect_Colors_06042026.xlsx` is the unchanged user-supplied
`(06042026) BẢNG MÀU DEFECT .xlsx` archived inside the Dashboard project.

The Dashboard HFPA worker copies this reference to its isolated
`Color_template.xlsx` before processing. Known defects use the supplied HEX
values, including the colors explicitly chosen in this reference. RGB is used
when a B/C row has no HEX. Names are matched after whitespace, punctuation and
known alias normalization (for example, Lacing → Lace).

New defects are registered only in that run's working copy by ColorManager;
the archived source stays unchanged. Re-Inspection, COPQ and quarterly report
palettes are not replaced by this reference.

Top 3 defects sort only by summed issue quantity descending. Equal quantities
retain the source order, without an alphabetical tie-break.
